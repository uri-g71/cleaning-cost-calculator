# מחשבון עלות כוח אדם בענף הניקיון

**[פתיחת המחשבון הפעיל](https://cleaning-cost-calculator.urigrabois678.chatgpt.site)**

לעבודה מכל מחשב או טלפון, פותחים את הקישור ונכנסים בחשבון שיש לו גישה לאתר. כפתור **שמירה** שומר את ההצעה בשרת. במכשיר אחר היא תופיע ב**הצעות שמורות**. הכפתור **שמירת הצעה במחשב** יוצר קובץ מקומי שאפשר להעביר ולפתוח ידנית.

## מה יש במאגר

זה עותק קוד של **גרסת אתר 20**: מחשבון עלות לשעה, שעות נוספות, קבוצות עובדים, עלויות אתר, שמירת הצעות וייצוא Excel ו־PDF. מקור הגרסה: `bcde8b77d00b368569c98cf459d5791ac039cec3`.

קוד החישוב, מבנה מסד הנתונים והבדיקות כלולים. מסד הנתונים הפעיל והצעות לקוחות אינם כלולים. תיקיית הבדיקות מכילה הצעת דמה לבדיקת תאימות. העלאה ל־GitHub אינה מעבירה הצעות ואינה מפרסמת עדכונים אוטומטית לאתר הפעיל.

## העלאה למאגר פרטי ללא שורת פקודה

1. בחשבון GitHub צור מאגר בשם `cleaning-cost-calculator`, בחר **Private** והשאר אותו ריק (ללא README או רישיון חדש).
2. פתח את המאגר ב־GitHub Desktop באמצעות **File → Clone repository** ובחר את המאגר שיצרת.
3. חלץ את קובץ ה־ZIP. העתק את **תוכן** התיקייה `cleaning-cost-calculator` אל תיקיית המאגר ששוכפלה, כולל תיקיות וקבצים המתחילים בנקודה. ברמת השורש צריכים להופיע `README.md`, `package.json` ו־`app/`.
4. ב־GitHub Desktop כתוב בשדה **Summary**: `מחשבון עלות – גרסה 20`. לחץ על **Commit to main** ואז **Push origin**.
5. פתח את המאגר ב־GitHub. הקישור בראש מסמך זה פותח את המחשבון המשותף גם מהמכשיר האחר.

## למפתח

- `lib/calculator.ts` ו־`lib/leave-costs.ts`: תמחור וזכויות. `lib/report.ts`, `lib/excel-rules.ts` ו־`lib/workbook-formulas.ts`: ייצוא Excel. `lib/print-report.ts`: הדפסה ו־PDF.
- `app/api/quotes/route.ts`: שמירה, פתיחה ומחיקה. `db/schema.ts` ו־`drizzle/`: מבנה הטבלאות והמיגרציות. הקוד מצפה למסד Cloudflare D1 בחיבור בשם `DB`.
- לפיתוח ולבדיקות ב־Linux/WSL עם Node.js 22.13 ומעלה: `npm ci`, אחר כך `npm test`. להפעלה מקומית: `npm run dev`. התקנה מקומית אינה מתחברת למסד האתר הפעיל.
- הרצה שוטפת אינה מחייבת חשבון GitHub: הקישור לאתר מופיע בראש מסמך זה. למעבר לאחסון עצמאי יש להקים סביבת Worker, לחבר D1, להחיל את המיגרציה ולהגדיר בקרת גישה לאתר ול־API לפני הוספת נתוני לקוחות. GitHub Pages לבדו מגיש אתר סטטי ואינו מריץ את שירות ההצעות.
- במאגר ההעברה הושמט מזהה הפרויקט של סביבת הפרסום הקיימת. החיבור הלוגי למסד הנתונים נשמר. הגדרות סביבת הייצור אינן מועתקות אוטומטית.

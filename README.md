# מחשבון עלות כוח אדם — גרסת GitHub Pages

מחשבון עברי לתמחור שירותי ניקיון. האתר פועל בדפדפן כיישום סטטי עצמאי, ללא שרת יישום, ללא Cloudflare וללא כניסה ל־ChatGPT.

## שמירת הצעות ופרטיות

- **שמירה בדפדפן** שומרת את ההצעה ואת תוצאות החישוב ב־localStorage, באותו מחשב, דפדפן וכתובת אתר בלבד. אין שליחת הצעות לשרת.
- **שמירת הצעה במחשב** מורידה HTML מקומי הכולל את מראה ההצעה והנתונים לפתיחה חוזרת. **פתיחה מהמחשב** מאפשרת לפתוח גם קבצים מהגרסה הקודמת.
- **גיבוי כל ההצעות לקובץ** מוריד JSON מקומי. **טעינת גיבוי מהמחשב** ממזגת אותו עם הרשימה הקיימת ומדלגת על עותקים זהים.
- ניקוי נתוני הדפדפן מוחק את הרשימה המקומית. יש לשמור גיבוי בתיקייה מקומית, שאינה מסונכרנת לענן אם מעוניינים באחסון מקומי בלבד.
- מחשב אחר מקבל רשימת הצעות נפרדת. להעברת הצעות יש לייצא גיבוי ולטעון אותו במחשב השני.
- הצעות מהאתר הקודם אינן עוברות אוטומטית. יש להוריד אותן שם לקובצי הצעה ולפתוח אותן כאן. אין למחוק את האתר הקודם לפני השלמת הגיבוי.
- אין לשמור קובצי הצעות, גיבויים, פרטי לקוחות או מסדי נתונים במאגר GitHub.

האתר דורש חיבור לצורך טעינת קובצי היישום. החישוב והשמירה מתבצעים מקומית. Excel, PDF והדפסת A4 ממשיכים להשתמש באותם מנגנונים ונוסחאות.

## הפעלה ופיתוח

נדרש Node.js 24.

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build:pages
```

`lib/calculator.ts`, `lib/leave-costs.ts` וקובצי נוסחאות ה־Excel נשמרו ללא שינוי במעבר. בדיקות השמירה מכסות פתיחה, עדכון, מחיקה, שחזור גיבוי, שמירת מחירים היסטוריים וכשלי אחסון.

## פרסום ב־GitHub Pages

תיקיית `docs` מכילה את הגרסה המוכנה לפרסום. אין צורך בחשבון שירות נוסף או בבנייה בשרת. במאגר יש לבחור **Settings → Pages → Deploy from a branch**, את הענף שמכיל גרסה זו ואת התיקייה **/docs**, ולשמור.

כתובת היעד לאחר הפעלת Pages:

https://uri-g71.github.io/cleaning-cost-calculator/

הכתובת הופכת לפעילה רק לאחר הפעלת Pages והשלמת הפרסום ב־GitHub. ב־GitHub Free נדרש מאגר ציבורי. אין לשנות מאגר פרטי לציבורי ללא אישור בעליו; שינוי כזה מפרסם גם את היסטוריית הקוד.

אחרי שינוי קוד יש להריץ `npm run build:pages` ולהעלות גם את תיקיית `docs` המעודכנת. אין להעלות את `node_modules`, גיבויי ההצעות או נתוני משתמשים.
